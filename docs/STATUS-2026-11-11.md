# Stakkz: requested changes and their status (11 November 2026)

Every request from the 11 November play session, what was done, where it lives in the code, and how it was checked.
"Verified" means checked in a real Chrome browser against a real server and PostgreSQL database, plus the automated suites listed at the end.

## Live site and data

| Request | Status | Notes |
|---|---|---|
| Newest version on stakkz.onrender.com | Done | `main` auto-deploys to Render service `stakkz`. Beta branch merged (PR #1). |
| Permanent free database | Done | Neon Postgres via `STAKKZ_DATABASE_URL` (set by the owner in Render). Neon free plan: 1 GB storage, 100 compute hours/month, no expiry. |
| Pasted connection strings must not break start-up | Done | `server.js` strips quotes and `channel_binding` from `STAKKZ_DATABASE_URL`. |
| Deploy overlap lost saves | Fixed | A newer server merges an older server's last save instead of failing every save until restart. Test: `tests/postgres-overlap.mjs`. |
| Delete beta leftovers | Owner action | Render service `stakkz-beta-test-20261111` and database `stakkz-beta-store` must be deleted in Render. The merged beta branch can be deleted on GitHub (the session's token was refused). |
| Rotate the Neon password | Owner action | It was pasted into chat. Reset it in Neon (Roles), paste the new string into Render without `&channel_binding=require` (now tolerated anyway). |

## Party settings and rules

| Request | Status | Where |
|---|---|---|
| One mode only: Classic, last player standing | Done, verified | Create page sends `mode: 'classic'`; mode selector removed. Timed modes remain in the engine but are not offered. |
| Exact number of players (2–6) | Done, verified | "Players in the party" setting; server caps seats and bots (`src/core.js` `max`). |
| Bots and difficulty | Done | Bots limited to party size − 1. |
| Turn timer: Off or fixed | Done, verified | Off (default), 20, 30, 45, 60 s. Nothing adjusts to player count. With it off, a player away 90 s can be skipped. |
| No free starting streets | Done, verified | `public/engine.js` `start`: nobody is handed deeds. |
| Starting money £2,500 | Done, verified | `START_CASH` in `public/engine.js`. |
| Rules text matches the game | Done | "How to play" (`RULES`) rewritten: goal, setting up, turn timer, stations, mortgages, loot boxes. Final Chaos removed from the rules (Classic has no clock). |
| Trains only between stations you own | Done, verified by tests | `railDest()` in the engine: you must own the station you land on and the destination. Free; ends the turn. Bots, highlights and the travel sheet follow it. Rento's exact rules could not be found online, so the rule is implemented as described. |
| Mortgages | Done, verified by tests | Mortgage for half the price; no rent while mortgaged; no building on a set with a mortgaged street; pay off for 55%. Bots and timeouts mortgage before going bankrupt. |
| Selling streets, houses and hotels | Done | Streets sheet and the street detail sheet: Build, Sell house / Downgrade, Mortgage, Pay off, Sell to bank. |
| Auto-end turn when nothing is left to do | Done | After rolling, if you cannot build and no offer is open, the turn ends after 1.4 s (retries after a sheet closes). |
| One loot box per lap, none at random | Done, verified by tests | Passing Start pays £200 and +1 loot box. Random drops and the loot box card are removed (the card now pays £100). |
